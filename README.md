# UTAKATA LAB

Static homepage for UTAKATA LAB, including the Beacon GEO featured report module and bilingual writing section.

## Files

- `index.html` is the publishable homepage.
- `case-folder/` contains portfolio and Beacon GEO visual assets used by the page.
- `hero-illustration.png` is the homepage hero artwork.
- `tools/` contains local asset-generation utilities.

## Publish

This site is designed to publish as a static root site on GitHub Pages, Vercel, or any static host. No build step is required.
